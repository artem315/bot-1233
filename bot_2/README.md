# BuilderBot — бот-строитель для Minecraft Java

Бот на Node.js и [mineflayer](https://github.com/PrismarineJS/mineflayer). Он заходит на сервер
и по командам из чата строит структуры из `.nbt` файлов (формат структурного блока).
Блоки ставятся «руками», через `bot.placeBlock`, команды `/setblock` и `/fill` не используются.

Используются только JS-библиотеки без нативной сборки, поэтому всё работает в Termux на Android:
`mineflayer`, `mineflayer-pathfinder`, `prismarine-nbt`, `vec3` и `prismarine-item`
(она и так ставится вместе с mineflayer, в `package.json` указана явно).

## Установка и запуск в Termux

1. Установите Termux (лучше из F-Droid) и обновите пакеты:
   ```sh
   pkg update && pkg upgrade
   pkg install nodejs git
   ```
2. Скопируйте папку `bot_2` на телефон, например через `git clone`, и перейдите в неё:
   ```sh
   cd bot_2
   ```
3. Установите зависимости:
   ```sh
   npm install
   ```
4. Запустите бота:
   ```sh
   node bot.js
   ```
   или `npm start`.

Совет: выполните `termux-wake-lock`, иначе Android может «усыпить» Termux при выключенном экране.

## Настройки

Файл `config.json`:

```json
{
  "host": "Artyo228.aternos.me",
  "port": 40864,
  "username": "BuilderBot",
  "auth": "offline"
}
```

Версию Minecraft указывать не нужно, бот определяет её сам. С `auth: "offline"` на сервере
должен быть выключен лицензионный режим (на Aternos: `Cracked` / `online-mode=false`).

## Права оператора

**Боту нужны права оператора.** Без них он не сможет сменить себе режим игры (`/gamemode`).
Выдайте права в консоли сервера или в игре:

```
/op BuilderBot
```

## Файлы структур

Положите `.nbt` файлы в папку `creating/bot_structures/`. Подойдут файлы, сохранённые
структурным блоком (Save mode): ванильный формат с полями `size`, `palette`, `blocks`, сжатый gzip.
В игре они лежат в `saves/<мир>/generated/minecraft/structures/`.

Для проверки в папке уже есть пример `domik.nbt` (домик 5×4×5). Если он не нужен, удалите его.
Когда в папке ровно один файл, он выбран по умолчанию.

## Команды в чате

| Команда | Что делает |
|---|---|
| `!структуры` | Показывает список `.nbt` файлов в папке |
| `!структура <имя>` | Выбирает файл для постройки (можно без `.nbt`) |
| `!режим creative` | Переходит в творческий режим, берёт блоки из креативного инвентаря и строит |
| `!режим survival` | Переходит в выживание, пишет, сколько блоков нужно и чего не хватает, и строит из того, что есть в инвентаре |
| `!режим adventure` | Только меняет режим: строить в нём нельзя |
| `!режим spectator` | Только меняет режим: строить в нём нельзя |
| `!стоп` | Останавливает стройку |

Структура строится от места, где бот стоял в момент команды `!режим`, со сдвигом
на 1 блок по X и Z, чтобы бот не замуровал себя. Сообщения самого бота он не обрабатывает.

## Как бот строит

- Слоями снизу вверх. Блоки `air` и `structure_void` пропускаются.
- В креативе бот летает (`bot.creative.flyTo`) и зависает на 2 блока выше текущего слоя.
  Летает отрезками (вверх, вбок, вниз), чтобы не врезаться в уже поставленные блоки.
- В выживании бот ходит с помощью `mineflayer-pathfinder`. Он ничего не ломает по дороге
  и не тратит блоки на «лесенки».
- Учитываются состояния блоков `facing`, `half`, `axis` и `type`: бот выбирает нужную опору,
  поворачивается и кликает в нужную половину грани. Так правильно встают брёвна, ступеньки,
  плиты (включая двойные), люки, печки, сундуки, двери, факелы на стенах, кнопки и другие блоки.
  Повёрнутые блоки ставятся через `bot._placeBlockWithOptions`. Это та же функция, которую
  вызывает `bot.placeBlock`, только ей можно передать поворот.
- Если нужной опоры нет, бот ставит блок как получится и пишет об этом в консоль.
- Верхние половины дверей и высоких растений и изголовья кроватей появляются сами,
  отдельно их бот не ставит.
- Жидкости, огонь и порталы руками не ставятся, они идут в «пропущено».
- Если на месте блока стоит что-то другое, бот это ломает.
- Ошибка на одном блоке не останавливает стройку. Если сервер отказал (например, на месте стоял моб),
  бот попробует ещё раз в конце слоя.
- В конце бот пишет в чат, сколько блоков поставлено и сколько пропущено.

## Структура проекта

```
bot_2/
├── bot.js                    — точка входа: подключение, события, логирование
├── config.json               — адрес сервера и имя бота
├── package.json
├── creating/bot_structures/  — .nbt файлы структур
└── src/
    ├── logger.js             — логирование в консоль
    ├── chat.js               — очередь сообщений в чат (защита от кика за спам)
    ├── structure.js          — чтение .nbt файлов (prismarine-nbt)
    ├── blockInfo.js          — блоки и предметы, правила установки по состояниям
    ├── inventory.js          — инвентарь: подсчёт, креативная выдача, взять в руку
    ├── builder.js            — стройка: перемещение, установка, статистика
    └── commands.js           — разбор команд из чата
```

## Логи

В консоль пишутся вход на сервер, сообщения чата, ход стройки, а также события
`kicked`, `error` и `end`.
